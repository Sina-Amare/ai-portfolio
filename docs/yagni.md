# Deliberately not built (yet)

| Not built                                                       | Why not now                                                                                                                                                        | Revisit when                                                                                            |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| Major upgrades: AI SDK 7, `@ai-sdk/*` 4, Vitest 5, TypeScript 7 | Same-major patches fix the audit advisories; majors need migration work with no user-visible gain.                                                                 | A needed feature or a security fix exists only in the new major.                                        |
| Full Content-Security-Policy                                    | Inline JSON-LD and the theme script would need nonces, which forces dynamic rendering.                                                                             | The site embeds third-party scripts or user-generated HTML.                                             |
| Distributed per-IP chat rate limiting in Redis                  | Per-instance memory limits + a Redis daily cap are proportionate at portfolio traffic.                                                                             | Abuse shows up in `/admin` or provider quota alerts.                                                    |
| Storing chat question free text                                 | Visitors may type personal data; topics + chip labels answer "what do people ask about".                                                                           | Owner explicitly wants raw questions and the privacy page says so.                                      |
| Separate `/projects/<id>` pages for workplace agents            | Private codebases, no repo/media; an anchored section is enough.                                                                                                   | There is public material (demo, write-up) worth its own URL.                                            |
| PWA install icons (192/512, apple-icon)                         | Nobody installs a portfolio; the static manifest is enough for browsers' theme and name.                                                                           | Analytics or the owner want a home-screen icon.                                                         |
| Localized 404 tab title / SSR'd 404 body                        | Needs a not-found `generateMetadata` Next doesn't document, or experimental `global-not-found`.                                                                    | A no-JS or 404 crawl complaint, or Next documents either.                                               |
| Test coverage numbers                                           | `@vitest/coverage-v8` isn't installed and nothing read the numbers; the dead config was removed.                                                                   | Someone will act on a coverage report (e.g. a review asks for it).                                      |
| E2E and the RAG eval blocking deploys                           | `vercel.json` gates on unit tests only: e2e needs a browser and minutes, the eval a network key.                                                                   | A regression ships that only e2e/eval would catch (then: Vercel Deployment Checks on the GitHub jobs).  |
| Model-based intent classifier for the chat                      | The regex classifier, relevance gate, prompt rules and leak guard pass all 102 red-team cases offline; a model call per message costs latency and free-tier quota. | The live red-team run shows attacks getting past all four layers, or real questions get canned replies. |
| Hybrid (lexical + vector) retrieval scoring                     | 14 deeper project questions in EN and FA (Persian spellings included) put the right project in the top 2 with embeddings alone.                                    | A golden case with a project or tool name misses its source in the top 5.                               |
| Persian mirror sections in `content/`                           | All 24 Persian golden questions retrieve the English notes (top scores 0.637–0.794); duplicates would crowd the top 6.                                             | A Persian golden case fails while its English twin passes.                                              |
| A NO_ANSWER sentinel from the model                             | The relevance gate refuses before any model call, and the prompt says what to do when the notes don't cover a question.                                            | Live answers guess on questions the notes don't cover, and a prompt rule can't stop it.                 |
